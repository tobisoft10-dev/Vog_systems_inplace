# Harici Bağlantılar ve Servisler

Bu dosya VOG Premium sisteminin entegre olduğu veya başvurduğu dış kaynak ve servis bağlantılarını listeler.

| Servis / Sistem | URL / Adres | Açıklama |
|---|---|---|
| **Labelary ZPL Engine** | `http://api.labelary.com/v1/printers/...` | ZPL etiketlerinin sanal PDF / PNG render önizlemesi için kullanılır |
| **Impinj Speedway Tünel** | `http://192.168.1.100` / TCP `5084` | RFID Tüneli yerel donanım adresi |
| **OmniSort Mini PLC** | `192.168.1.50` / TCP `2000` | Sorter donanım kontrol PLC'si |
| **Logo Tiger 3 ERP MSSQL** | `localhost:1433` | Logo MSSQL veritabanı |
| **VOG Local WMS Web** | `http://localhost:3000` | Canlı kullanıcı web arayüzü |
| **VOG Local API** | `http://localhost:3001` | Canlı Node.js WMS RESTful API |
